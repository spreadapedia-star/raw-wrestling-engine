# Development workflow

- `main`: stable, reviewed builds.
- `dev/chatgpt`: ChatGPT-authored work.
- `dev/claude`: proposed Claude branch; create when Claude is ready.
- Merge via pull requests with test notes and review.
- Claude and ChatGPT do not automatically share conversations, local files or account access.
- Keep existing SNES Super WrestleMania and WWF Raw ROM-hack work in separate repositories/workspaces.
- Every milestone should include a Windows build procedure, reproducible test results, known limitations, and a short change log.
- Do not commit ROM files, credentials, or copyrighted sprite/audio dumps.
